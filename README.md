# PJ Data Labs

Personal site for Phillip Haberman: portfolio, projects, writing, and videos. Static HTML, CSS, and a small theme script. No build step.

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

## Layout

- `index.html`, `projects.html`, `writing.html`, `videos.html`, `about.html` — pages
- `posts/` — articles
- `css/style.css`, `js/theme.js` — styles and light/dark toggle
- `img/` — images, named to match the article they belong to
- `my_resume.pdf` — resume linked from the home and about pages
